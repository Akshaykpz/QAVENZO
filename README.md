# QAVENZO — Creative & Digital Growth Agency

> **CREATE • CONNECT • GROW**

A modern, high-impact creative agency website built with **React 19**, **TypeScript**, **Vite**, and **Tailwind CSS**.

---

**QAVENZO** is a creative and digital growth agency crafting high-conversion content, brand identities, custom web platforms, and performance marketing campaigns.

- **Services**:
  - `01 CONTENT` — Social content, reels, AI video, campaign creatives, copywriting

  - `03 WEB` — Business websites, landing pages, portfolio websites, e-commerce, web experiences
  - `04 MARKETING` — Social media management, Meta advertising, Google advertising, growth strategy
  - `05 BRANDING` — Logo design, brand identity, visual language, brand guidelines
  - `06 SOCIAL MEDIA` — Instagram management, content planning, stories, reels, community management

---

## ⚡ Tech Stack

- **Framework**: React 19 with TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS & Vanilla CSS Design System
- **Animations**: Framer Motion
- **Icons**: Lucide React & Custom SVG Brand Icons
- **Effects**: Canvas Confetti

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```

The application will start at `http://localhost:5173/`.

### 3. Production Build
```bash
npm run build
```

The optimized production bundle will be generated in `dist/`.
